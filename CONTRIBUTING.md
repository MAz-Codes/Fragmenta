# Contributing to Fragmenta

Thank you for your interest in Fragmenta.

## Start with an Issue

Before writing code or opening a pull request, please file an issue describing the bug, proposed change, or feature you want to work on. This gives me a chance to discuss the idea, confirm that it fits Fragmenta's direction, and agree on an approach before any implementation.

Please do not submit unsolicited pull requests for substantial changes. Pull requests that implement work which has not first been discussed in an issue may be closed without review.

Once an issue has been discussed, wait for confirmation before starting significant implementation work. When opening a pull request, link it to the relevant issue and explain what changed and how it was tested.

## Security Reports

Please do not disclose security vulnerabilities in a public issue. Contact me privately through the email address listed in the repository instead.
